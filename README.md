# 希顶语→汉字 RIME 输入方案

℞ DGCK81LNN/rime-xdi8

由希顶到汉字的 RIME 输入方案。

* 希顶·聊天字母 `lnn_xdi8`

  使用聊天字母码位通过〇改希顶语输入简体字，支持部首简单模糊匹配，Shift+Q/W/S/Z/X/C 选择候选，`` ` `` 进入拼音反查。

未来可能加入更多方案。

## 依赖

* 简化字八股文 [℞ essay-simp](https://github.com/rime/rime-essay-simp)
* 袖珍简化字拼音 [℞ pinyin-simp](https://github.com/rime/rime-pinyin-simp)（拼音反查用）

## 安装

1. 确保已安装上述依赖方案。
2. 将 `lnn_xdi8.schema.yaml` 及相关文件放入 RIME 用户文件夹。
3. 重新部署 RIME。

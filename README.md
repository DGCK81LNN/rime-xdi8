# 希顶语→汉字 RIME 输入方案

℞ DGCK81LNN/rime-xdi8

由希顶到汉字的 RIME 输入方案。

* 希顶·聊天字母 `lnn_xdi8`

  使用聊天字母码位通过〇改希顶语输入简体字，支持部首简单模糊匹配，Shift+Q/W/S/Z/X/C 选择候选，`` ` `` 进入拼音反查。

未来可能加入更多方案。

* [℞ pinyin-simp](https://github.com/rime/rime-pinyin-simp) 袖珍简化字拼音（拼音反查用）
